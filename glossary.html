Mathematical glossary#

Short explanations of mathematical terms used throughout the documentation. Linked terms show a preview on hover or keyboard focus; follow a link to read its entry here.

basis of a vector space#

A collection of vectors such that every vector in the space can be written in exactly one way as a finite linear combination of them. For example, \((1,0,0)\), \((0,1,0)\), and \((0,0,1)\) form a basis of \(K^3\): the coefficients in the combination are simply the three coordinates. The number of basis vectors is the dimension of the vector space.

dendrogram#

A hierarchy of nested clusters indexed by a scale. At each scale, the clusters form a partition of the observations; as the scale increases, clusters may merge but never split. It is commonly drawn as a tree whose leaves are observations and whose branch heights indicate when clusters merge.

direct sum of vector spaces#

A way to combine vector spaces while keeping their contributions independent. A vector in \(V \oplus W\) is a pair \((v,w)\), with \(v\in V\) and \(w\in W\); addition and scalar multiplication act on each coordinate separately. For example, \(K^2\oplus K^3\) is isomorphic to \(K^5\). For an infinite collection of spaces, only finitely many coordinates of each vector may be nonzero.

freely generated vector space#

Think of a set \(S\) as an alphabet. Just as letters are building blocks for words, the elements of \(S\) supply the building blocks for vectors. Here we combine them using addition and scalar multiplication. Unlike letters in a word, their order in a sum does not matter, and repeated letters combine: for example, \(e_a+e_b+e_a=2e_a+e_b\).

“Free” means that we impose no extra identifications beyond the rules of a vector space. Distinct letters give independent vectors: we do not, for example, declare \(e_c=e_a+e_b\).

A vector space freely generated by a set \(S\) has one basis vector \(e_s\) for each element \(s\in S\). Its vectors are finite linear combinations of these basis vectors, with coefficients in a field \(K\), and each such expression is unique. For example, a set with three elements generates a copy of \(K^3\), with basis \(e_1,e_2,e_3\). Taking \(K=\mathbb{R}\), one vector is

\(v = 2e_1 - 3e_2 + 0e_3\).

Its coefficients are \((2,-3,0)\): no different choice of coefficients gives the same vector. If the basis is infinite, each vector still uses only finitely many nonzero coefficients. No relations between the basis vectors are imposed.

injective map#

A map is injective (or one-to-one) if distinct elements of its source have distinct images. Equivalently, \(f(x)=f(y)\) implies \(x=y\). Each element of the target has at most one preimage; some target elements may have none. For example, \(f:K\to K^2\), \(f(a)=(a,0)\), is injective, but is not surjective because it never reaches a pair with a nonzero second coordinate.

isomorphism#

A map that preserves the relevant mathematical structure and has an inverse that also preserves it. Objects related by an isomorphism have the same structure, though their elements may be represented differently. For vector spaces, an isomorphism is an invertible linear map. For example, \((a,b)\mapsto(b,a)\) is an isomorphism from \(K^2\) to itself.

kernel of a linear map#

The vectors that a linear map sends to zero. For \(f:V\to W\), the kernel is \(\ker f=\{v\in V\mid f(v)=0\}\) and is a vector subspace of \(V\). For example, the kernel of \(f(a,b)=a+b\) consists of all pairs \((a,-a)\). A linear map is injective exactly when its kernel contains only the zero vector.

preimage#

For a map \(f:X\to Y\), a preimage of an element \(y\in Y\) is an element \(x\in X\) such that \(f(x)=y\). There may be no such element, one, or several. For example, under \(f:\mathbb{R}\to\mathbb{R}\), \(f(x)=x^2\), both \(2\) and \(-2\) are preimages of \(4\).

The notation \(f^{-1}(\{y\})\) denotes the set of all preimages of \(y\); it does not require \(f\) to have an inverse function. More generally, the preimage of a subset \(B\subseteq Y\) is \(f^{-1}(B)=\{x\in X\mid f(x)\in B\}\).

principal submatrix#

A matrix obtained from a square matrix by keeping the same selection of rows and columns. For an index set \(S\), it is written \(M[S,S]\). For example, keeping the first and third rows and columns of a \(3\times 3\) matrix gives

\(\begin{pmatrix} m_{11} & m_{13} \\ m_{31} & m_{33} \end{pmatrix}\).

For a distance matrix, this retains all pairwise distances between the selected points.

simplicial complex#

An abstract simplicial complex is a collection of finite nonempty sets, called simplices, that contains every nonempty subset of each simplex. The elements of these sets are called vertices. A simplex with \(k+1\) vertices has dimension \(k\): a singleton is a vertex, a pair is an edge, and a triple is a filled triangle. Larger sets describe higher-dimensional analogues: four vertices form a filled tetrahedron, and so on.

For example, including \(\{a,b,c\}\) requires including its three edges and three vertices. The three edges can also occur without the filled triangle, giving just its boundary. “Abstract” means the complex records which vertices form simplices; no coordinates or embedding in Euclidean space are required. Some conventions also include the empty set as a simplex.

surjective map#

A map is surjective (or onto) if every element of its target is the image of at least one element of its source. Several source elements may have the same image. For example, \(f:K^2\to K\), \(f(a,b)=a+b\), is surjective because every \(c\in K\) is the image of \((c,0)\).
