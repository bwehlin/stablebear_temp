stablebear.distributions#

Distributions with weight evaluation for plotting and stablebear.random.subsample_relative(). See Distributions for an overview of the available distributions and Relative subsampling for sampling examples.

Distributions with weight evaluation for plotting and relative subsampling.

Gaussian and bounded Uniform weights are normalized densities. Unbounded Uniform intervals use weight one on their support. Mixture coefficients sum to one independently of the supplied values. Use weight(values) with finite scalar or array-like filter values to evaluate weights. Sampling normalizes the combined weights over the reference points.

class stablebear.distributions.Distribution#

Abstract base class for stablebear’s built-in distributions.

abstract plot_range()#

Return suggested plotting bounds as (lower, upper).

Either endpoint may be infinite for an unbounded distribution.

abstract weight(values)#

Evaluate weights at finite real filter values.

Parameters:

values (float or array_like) – Finite real filter values, of any shape.

Returns:

Scalar input returns a float; array-like input returns a float64 array with the same shape.

Return type:

float or numpy.ndarray

class stablebear.distributions.Gaussian(mean: float = 0.0, std: float = 1.0)#

Bases: Distribution

Gaussian distribution with mean mean and standard deviation std.

Parameters:

  • mean (float, optional) – Finite center of the weighting function, by default 0.

  • std (float, optional) – Finite positive standard deviation, by default 1.

Notes

Weights are the normalized density exp(-0.5 * ((value - mean)/std)**2) / (std * sqrt(2*pi)).

plot_range()#

Return (mean - 3*std, mean + 3*std) for plotting.

weight(values)#

Evaluate the normalized Gaussian density at finite filter values.

Parameters:

values (float or array_like) – Finite real filter values, of any shape.

Returns:

Density values. Scalar input returns a float; array-like input returns a float64 array with the same shape.

Return type:

float or numpy.ndarray

class stablebear.distributions.Uniform(start: float = 0.0, end: float = 1.0)#

Bases: Distribution

Uniform distribution on [start, end), with unbounded intervals allowed.

Parameters:

  • start (float, optional) – Inclusive lower bound, by default 0. May be negative infinity.

  • end (float, optional) – Exclusive upper bound, greater than start, by default 1. May be positive infinity.

Notes

A bounded interval has density 1 / (end - start) on its support. If either endpoint is infinite, the weight is one on the interval; this special case does not define a normalized probability density.

plot_range()#

Return (start, end); unbounded endpoints remain infinite.

weight(values)#

Evaluate the interval’s density, or unit weights if unbounded.

Parameters:

values (float or array_like) – Finite real filter values, of any shape.

Returns:

Weights on [start, end), zero elsewhere. Scalar input returns a float; array-like input returns a float64 array with the same shape.

Return type:

float or numpy.ndarray

class stablebear.distributions.Mixture(distributions: tuple, coefficients: tuple)#

Bases: Distribution

A mixture of distributions with coefficients normalized to sum to one.

Parameters:

  • distributions (sequence of Distribution) – Nonempty component sequence, which may include nested mixtures.

  • coefficients (sequence of float) – Mixing coefficients, one per component. Must be finite and nonnegative, with at least one positive. Normalized to sum to one at construction.

Notes

The weight method sums component weights using the stored coefficients. Evaluation is independent of the other supplied values. A positive-coefficient unbounded Uniform component, including one in a nested mixture, makes the mixture unnormalized as a continuous density. Relative subsampling normalizes the combined weights over the reference points once; it does not normalize each component over those points. Components and coefficients are stored as immutable tuples.

plot_range()#

Return the range spanning all positive-coefficient components.

Uses each component’s plot_range(), including nested mixtures. A positive-coefficient unbounded Uniform component makes the range unbounded too.

weight(values)#

Evaluate the weighted sum of the component densities or weights.

Parameters:

values (float or array_like) – Finite real filter values, of any shape.

Returns:

Scalar input returns a float; array-like input returns a float64 array with the same shape. Values are not normalized over the array.

Return type:

float or numpy.ndarray

Notes

A component that is zero at an evaluation point contributes zero there; the other coefficients remain unchanged.
